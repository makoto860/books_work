## 開発背景
前職の製本業務では、作業場所が分かれていたため、各工程の進捗状況が把握しづらい課題がありました。

進捗確認を口頭や個別確認で行う場面が多く、
確認工数の増加や情報共有漏れが発生していました。

そこで、案件ごとの仕様情報と作業状況を
一元管理できるアプリケーションを開発しました。

各工程の進捗状況をリアルタイムで確認できるようにし、
現場全体の状況を把握しやすい構成を意識しています。
🟥こだわりのポイントなど、アピールできる内容<br>
他の場所で作業していると作業状況が分かりづらく作業がやりづらい、情報が分散してしまうことで認識のズレが生じるという課題を解決したいと考え、本アプリを設計しました。
製本ごとに作業状況や履歴を管理できるようにすることで、現在の進捗だけでなく過去の作業内容も確認でき、全体の状況を把握しやすくしています。
また、ユーザー認証機能を導入し、関係者以外が操作できないようにすることで、実際の運用を意識した設計としました。
実務での利用を想定し、情報の共有と管理のしやすさを重視して開発しています。

🟥開発の背景<br>
以前製本の仕事を経験していたのでそこで不便に思ったことを改善したいと思いました。<br>
仕様書見つけるのが難しかった。<br>
仕様書を直接渡す必要があった。<br>
他の階で作業しているので仕事の進捗を聞く必要がある。<br>
以上を不便に感じました。

🟥改善案<br>
仕様書を検索、並び替えを追加することで大量にある仕様書の中から見つけやすくすることで業務効率を上げる。<br>
仕様書を電子化することで他の場所にいてもリアルタイムで確認することができ、直接移動しなくても共有することが簡単にできる。<br>

🟥ポートフォリオで使用している技術や機能<br>
アカウント、仕様書、作業進捗を登録、情報閲覧、編集、削除する機能。<br>
アカウント、仕様書、作業進捗を登録するときに日付など制限をかけられる機能。<br>
dartsass-rails、bootstrap、deviseを使用。<br>
fontawesomeを使用。<br>
検索、並び替え機能。<br>
納期の近い順でスライドを表示させる機能。
