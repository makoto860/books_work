🟥アプリ名<br>
製本管理システム

🟥開発の背景（なぜ作ったのか）<br>
以前製本の仕事を経験していた。<br>
仕様書見つけるのが難しかった。<br>
仕様書を直接渡す必要があった。<br>
他の階で作業しているので仕事の進捗を聞く必要がある。<br>
以上を不便に感じました。

🟥改善案<br>
仕様書を検索、並び替えを追加することで大量にある仕様書の中から見つけやすくすることで業務効率を上げる。<br>
仕様書を電子化することで他の場所にいてもリアルタイムで確認することができ、直接移動しなくても共有することが簡単にできる。<br>

🟥操作方法<br>
初めはログイン画面になる。<br>
新規アカウント登録する。<br>
アカウントが作成され仕様書を登録、情報閲覧、編集、削除する。<br>
仕様書を登録したデータに作業進捗を登録、情報閲覧、編集する。<br>
ログアウトできる。<br>
以降登録したメールアドレス、パスワードでログインする。

🟥ポートフォリオで使用している技術や機能<br>
テストアカウントを用意。<br>
メールアドレス：`test@example.com`<br>
パスワード：password<br>

アカウント、仕様書、作業進捗を登録、情報閲覧、編集、削除する機能。<br>
アカウント、仕様書、作業進捗を登録するときに日付など制限をかけらる機能。<br>
dartsass-rails、bootstrap、deviseを使用。<br>
fontawesomeを使用。<br>
検索、並び替え機能。<br>
納期の近い順でスライドを表示させる機能。

言語<br>
ruby on railsで開発。<br>
HTML、CSS、JavaScriptを使用。<br>
開発環境<br>
ruby -v 3.3.3 (2024-06-12 revision f1c7b6f435) [arm64-darwin24]<br>
rails -v 8.0.4<br>
開発でsqlite3を使用、本番環境でPostgreSQLを使用。<br>
GitHubでプルリクエスト、Herokuでデプロイ。
